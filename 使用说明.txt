========================================================================
             西沃智慧宠物 · 班级双端交互激励系统（部署与使用指南）
========================================================================

一、系统概述
本系统专为机房有线局域网环境设计，无需互联网连接，无需配置外部数据库，
所有数据保存在本地 data 目录下。

教师机运行独立可执行程序（xiwo-pet-server.exe），同时作为服务器与大屏管控台；
机房学生通过浏览器访问教师机局域网 IP 地址即可进入个人专属宠物系统。

------------------------------------------------------------------------
二、快速使用流程

【第一步：教师机启动服务】
双击运行目录下的「后台静默启动.vbs」（或全英文别名 start_silent.vbs）。
服务将在后台静默拉起，不占用命令行窗口，并自动在默认浏览器中打开教师管控大屏：
  ?? http://localhost:3000/teacher

如需查看后台输出日志，可双击运行「启动服务(控制台).bat」。

【第二步：告知学生访问地址】
在教师机按 Win + R 输入 cmd，运行 ipconfig 查看本机 IPv4 地址（如 192.168.1.100）。
或在控制台启动日志中直接查看提示。
学生在各自 PC 的浏览器（Edge/Chrome）地址栏中输入：
  ?? http://[教师机IP]:3000
系统将自动进入学生登录界面。

【第三步：学生登录】
- 账号：学号编号（如 1 号学生输入 s01，2 号学生输入 s02，以此类推至 s45）
- 初始密码：统一为 123
- 学生登录后可在个人界面修改密码，防冒用。教师也可随时在管控台一键重置。

------------------------------------------------------------------------
三、课堂核心模式与控制权

教师端顶部提供一键模式切换条，学生端根据模式自动上锁或解锁对应权限：

1. 上课模式（默认模式）
   学生端自动锁定所有抚摸、喂食与装扮按钮，提示学生专注听讲。
   教师在大屏随时点击学生卡片加分（+1 发言积极 / +2 小组互助 / +5 精彩表现）。

2. 自由互动模式
   教师可在互动答题或自主练习环节开启。
   学生端解锁抚摸互动与美味小零食投喂，消耗课堂币，增加饱腹度与经验值。

3. 装扮创作时间（限时 5 分钟）
   通常在下课前 5 分钟由教师点击开启。
   学生端解锁「装扮工坊」，可自由挑选饰品、微调色相，并输入作品名称提交。

4. 课间休息模式
   学生可自由浏览装扮广场并为同学作品点赞。

5. 下课归档
   宠物进入休眠状态，自动完成数据存档。

------------------------------------------------------------------------
四、装扮创作、AI 预审与广场上架机制

1. 创作与提交：
   学生在装扮工坊设计完毕后，点击「发布到装扮广场」。

2. 本地 AI 预审：
   系统内置毫秒级本地规则引擎（无需联网），自动对装扮名称进行敏感词检测、
   饰品合理性校验。违规名称将直接拦截并给出具体提示。

3. 教师端审核：
   AI 初审通过的作品，教师管控大屏的「装扮审核」按钮将实时亮起红点计数。
   教师点击进入审核队列，可实时预览学生搭配的宠物效果与 AI 评分，
   一键点击「批准上架」或「退回修改」。

4. 班级广场展示与互赞：
   通过审核的作品即刻出现在全体学生的「装扮广场」中。
   每名同学可点赞支持，作者每次获赞将获得 2 课堂币奖励。

------------------------------------------------------------------------
五、管理脚本清单

- 后台静默启动.vbs (start_silent.vbs)   : 后台隐藏窗口静默启动服务并打开大屏
- 启动服务(控制台).bat (start_server_console.bat) : 带控制台黑色窗口启动（排查日志用）
- 停止服务.bat (stop_service.bat)       : 双重核查并释放 3000 端口，彻底停止服务
- 检查运行状态.bat (check_status.bat)   : 查看进程与端口运行情况
- 注册开机自启.bat (install_autorun.bat): 设置教师机开机自动静默启动
- 注销开机自启.bat (uninstall_autorun.bat) : 注销开机自启注册项
- 打开教师大屏.bat (open_teacher_console.bat) : 快速在浏览器打开教师管控页面

------------------------------------------------------------------------
六、数据备份与维护

运行时数据存放在当前目录的 data/ 文件夹中：
- students.json    : 45 名学生账号、密码哈希与宠物成长状态
- outfits.json     : 装扮库与审核记录
- logs.json        : 课堂全部操作流水记录
- config.json      : 班级名称与教师密码配置

教师管控台提供「数据备份」按钮，一键下载完整 JSON 备份包。
