# 西沃智慧宠物 · 班级双端交互激励系统 (`xiwo-pet-server`)

面向机房有线局域网环境的班级双端交互激励系统，无需互联网连接或外部数据库，所有运行时数据保存在本地 `data/` 目录中。教师机运行服务端并提供教师大屏管控台，学生通过机房浏览器访问教师机局域网地址即可进入个人电子宠物界面。

## 主要功能

- **课堂模式控制**：支持上课模式、自由互动模式、装扮创作时间、课间休息模式与下课归档，学生端按钮权限随模式自动锁定或解锁。
- **教师大屏管控**：支持课堂加分、全班加分、装扮审核队列、排行榜设置与重置、学生密码重置以及完整 JSON 数据备份。
- **学生电子宠物互动**：包含抚摸、投喂、每日签到、拜访同学、图鉴收集与装扮工坊（支持背景、头像框、称号、饰品购买与装备）。
- **本地装扮预审**：内置离线规则引擎对装扮名称进行敏感词与合理性校验，通过后进入教师大屏审核队列。
- **排行榜与段位系统**：支持总积分榜、黑马周榜及段位成长体系。
- **一体化控制台与保活升级**：提供 `scripts/console.ps1` 与 `scripts/ConsoleLauncher.cs`（可编译为 `电子宠物控制台.exe`），支持保活服务安装、启停、前台调试、打包升级包及保留数据的自动合并升级。

## 目录结构

```text
├── src/
│   ├── server.js                 # Express + WebSocket 服务入口
│   ├── routes/                   # student / teacher / internal 路由
│   ├── services/                 # data-store、score-helper、ranking-helper 等服务
│   ├── ws/                       # WebSocket 广播模块
│   └── public/                   # 学生端、教师大屏端及共享资源
├── scripts/                      # 控制台、服务安装、升级部署与打包脚本
├── 电子宠物入口.html             # 学生端快捷入口
├── 教师大屏入口.html             # 教师大屏快捷入口
├── 使用说明.txt                  # 机房部署与使用指南
├── CHANGELOG.md                  # 版本更新记录
├── VERSION                       # 当前版本号
└── package.json
```

## 快速运行

```bash
npm install
npm start
```

默认监听端口 `3001`：
- 学生端：`http://[教师机IP]:3001/student/`
- 教师大屏：`http://[教师机IP]:3001/teacher/`

Windows 机房部署可直接查看根目录的 `使用说明.txt`。
